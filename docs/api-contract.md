# API Contract

Base URL for local development:

```text
http://localhost:8000
```

All endpoints return JSON. Error responses use FastAPI's standard shape:

```json
{
  "detail": "message"
}
```

Every response includes:

- `X-Request-ID`: request correlation ID, generated by the API or echoed from the incoming header
- `X-Process-Time-ms`: server-side request duration in milliseconds

## Health

### `GET /health`

Liveness check. Does not require database access.

Response:

```json
{
  "status": "ok",
  "service": "capital-markets-api",
  "environment": "development"
}
```

### `GET /health/ready`

Readiness check. Executes a lightweight database query.

Response:

```json
{
  "status": "ready",
  "service": "capital-markets-api",
  "environment": "development"
}
```

## Tickers

### `GET /tickers`

Returns active tickers by default.

Query parameters:

- `search`: optional symbol search string
- `active_only`: default `true`
- `limit`: default `50`, max `200`
- `offset`: default `0`

Response:

```json
{
  "items": [
    {
      "id": 1,
      "symbol": "AAPL",
      "name": "AAPL",
      "asset_type": "equity",
      "exchange": null,
      "currency": "USD",
      "is_active": true
    }
  ],
  "limit": 50,
  "offset": 0,
  "count": 1,
  "total": 1,
  "search": null,
  "active_only": true
}
```

## Market Data

### `GET /market-data/{symbol}`

Returns stored historical OHLCV prices. This endpoint reads from PostgreSQL and does not call the external market data provider.

Query parameters:

- `start_date`: optional ISO date
- `end_date`: optional ISO date
- `limit`: default `252`, max `1500`
- `offset`: default `0`

Response:

```json
{
  "symbol": "AAPL",
  "start_date": null,
  "end_date": null,
  "items": [
    {
      "price_date": "2024-01-02",
      "open": "185.64",
      "high": "188.44",
      "low": "183.89",
      "close": "185.40",
      "adjusted_close": "185.40",
      "volume": 82488700
    }
  ],
  "limit": 252,
  "offset": 0,
  "count": 1,
  "total": 1
}
```

Query parameters:

- `start_date`: optional ISO date

  "start_date": null,
  "end_date": null,

      "metric_date": "2024-01-02",

## Top Movers

### `GET /top-movers`

Ranks symbols by stored `daily_return` for a metric date.

Query parameters:

- `metric_date`: optional ISO date; defaults to latest available metric date
- `direction`: `gainers` or `losers`, default `gainers`
- `limit`: default `10`, max `50`

Response:

```json
{
  "items": [
    {
      "symbol": "MSFT",
      "metric_date": "2024-01-02",
      "daily_return": "0.05",
      "volume_ratio_20d": "1.4",
      "close": null
    }
  ],
  "metric_date": "2024-01-02",
  "direction": "gainers",
  "limit": 10,
  "count": 1
}
```

## ETL

### `POST /etl/run`

Starts an ETL job for one or more symbols. The endpoint returns `202 Accepted`.

Symbols are normalized to uppercase. With the Stooq provider, plain symbols default to US listings; provider-specific symbols can include a suffix such as `SHOP.TO`. The fixture provider accepts any valid symbol for deterministic local demo data.

Request:

```json
{
  "symbols": ["AAPL", "MSFT", "SPY"],
  "start_date": "2024-01-01",
  "end_date": null
}
```

Response:

```json
{
  "id": 1,
  "job_type": "market_data",
  "status": "succeeded",
  "symbols": ["AAPL", "MSFT", "SPY"],
  "started_at": "2024-01-01T12:00:00Z",
  "finished_at": "2024-01-01T12:00:08Z",
  "rows_extracted": 750,
  "rows_loaded": 750,
  "error_message": null,
  "metadata_json": {
    "provider": "stooq"
  }
}
```

### `GET /etl/status`

Returns recent ETL jobs.

Query parameters:

- `status`: optional `pending`, `running`, `succeeded`, or `failed`
- `limit`: default `20`, max `100`
- `offset`: default `0`

Response:

```json
{
  "items": [],
  "limit": 20,
  "offset": 0,
  "count": 0,
  "status": null
}
```

## AI Reports

### `POST /reports/generate`

Generates and persists an AI report from stored computed metrics. The endpoint returns `201 Created`.

Request:

```json
{
  "symbol": "AAPL",
  "report_date": "2024-01-31",
  "report_type": "daily"
}
```

Response:

```json
{
  "id": 1,
  "symbol": "AAPL",
  "report_date": "2024-01-31",
  "report_type": "daily",
  "summary": "AAPL report generated from stored metrics for 2024-01-31.",
  "trend_insights": ["Weekly return remains positive."],
  "anomaly_explanations": ["Detected signal: unusually high volume"],
  "risk_notes": ["Review drawdown and volume persistence before acting."],
  "metrics_snapshot": {
    "symbol": "AAPL",
    "report_date": "2024-01-31",
    "daily_return": "0.025"
  },
  "model": "local-fallback",
  "created_at": "2024-01-31T12:00:00Z"
}
```

### `GET /reports/{symbol}`

Returns persisted reports for a symbol.

Query parameters:

- `limit`: default `10`, max `50`
- `offset`: default `0`

Response:

```json
{
  "symbol": "AAPL",
  "items": [],
  "limit": 10,
  "offset": 0,
  "count": 0,
  "total": 0
}
```

## Common Status Codes

- `200 OK`: read request succeeded
- `201 Created`: report generated and stored
- `202 Accepted`: ETL request accepted and executed
- `404 Not Found`: requested ticker or report input was unavailable
- `422 Unprocessable Entity`: invalid symbol, date range, pagination, or request body
- `503 Service Unavailable`: readiness check failed because the database is unavailable
